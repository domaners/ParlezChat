Stage all changes, create a commit with a concise descriptive message summarising what was changed, and push to origin.

Steps:
1. Add a major increment to the Android application version number.
2. Run `git add -A` to stage all changes
3. Run `git status` to see what is staged
4. Based on the staged files, write a short but descriptive commit message (imperative mood, e.g. "Add save-word feature and WhatsApp theme")
5. Run `git commit -m "<message>"`
6. Run `git push origin` to push to the remote
7. Report the commit hash and message to the user
